# Материалы по развёртыванию SborkaPC

В этой папке хранятся скриншоты и материалы, подтверждающие настройку и запуск проекта.

## Отдельный репозиторий деплоя

Конфигурация Docker Compose и Nginx вынесена в отдельный репозиторий:

https://github.com/Slouwen/SborkaPC_SYBAU-deploy

В репозитории деплоя находятся:
- `docker-compose.yml` — запуск приложения и Nginx;
- `nginx/nginx.conf` — обратный прокси и HTTPS;
- `certs/` — локальные сертификаты (не добавлять приватный ключ в Git);
- `.gitignore` — исключение локального окружения и сертификатов.

## Скриншоты

Добавляйте в папку `screenshots/` изображения настройки, сборки и запуска приложения.
